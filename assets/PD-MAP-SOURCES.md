Wikimedia Commons file page; the exact license template found in the file's wikitext
is quoted in the **License / PD evidence** column. Only items confirmed public-domain
and free for commercial use are included.

## Reasoning log

1. Started from Wikimedia Commons "Old maps of [city]" categories for each target city, filtering for actual
   city/street plans in the 1850–1925 window (excluding regional/vilayet maps, OSM renders, and post-1948 maps).
2. For each shortlisted file, opened the file page AND re-fetched the raw wikitext (`?action=raw`) to read the
   exact license template rather than trusting category-level claims.
3. Accepted only files carrying an explicit PD template: `PD-old`, `PD-old-70-1923`, `PD-old-100-1923`,
   `PD-US-expired`, `PD-France`, `PD-Israel`, `PD-Syria`, or `PD-old-assumed`. Recorded direct
   `upload.wikimedia.org` URLs and pixel dimensions for print suitability.
4. Preferred the highest-resolution confirmed file per city for the print master, and noted lower-res or
   weaker-tag alternatives as secondaries.

## Cities lacking a confirmed source

- **Antakya / Antioch — NO confirmed-PD source found.** The most-cited candidate (the *Antioch / Antakiyeh*
  city plan, Wagner & Debes for Baedeker, 1912) does NOT appear to be uploaded to Wikimedia Commons; it is only
  offered by commercial print sellers, so no verifiable license could be confirmed. The one 1850–1925-era
  Commons image in Category:Maps of Antioch ("The museum of classical antiquities, 1860") actually depicts the
  **port of Seleucia Pieria, not the city of Antioch**, and carries only `{{Flickr-no known copyright restrictions}}`,
  which is NOT a definitive PD statement — therefore excluded. A Library of Congress search returned only a 1952
  geological map. Recommend sourcing the Baedeker 1912 plan directly from a digitized Baedeker handbook
  (e.g. Internet Archive / BnF Gallica) and re-verifying before commercial use.

## Caveats for the team

- **Tripoli (Lebanon):** only a 1933 map is confirmed PD on Commons — slightly outside the ideal pre-1925 window.
  A 1912 Baedeker "Tripoli (Tarabulus) & El Mina" plan exists but was not found on Commons with a verifiable license.
- **`PD-old-assumed`** (Jaffa, Aleppo plan) means PD is assumed because the work is >120 years old with no known
  author/death date — robust for these pre-1900 works but technically an assumption rather than a proven death date.
- **`PD-Syria`** (Aleppo 1912) is recognized by Commons but is a country-of-origin tag; the same file also qualifies
  as PD in the US by age. The Gallica Aleppo plan (triple-tagged) is the safer commercial choice.
- No binary files were downloaded or committed. All direct URLs point to Wikimedia Commons originals.
